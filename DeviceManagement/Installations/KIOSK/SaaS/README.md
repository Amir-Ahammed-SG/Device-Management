# SaaS KIOSK setup

Choose **SaaS > KIOSK > KIOSK Installation** in Device Management.
The existing installation menu starts this handler directly and returns to
Back/Main Menu/Exit after completion. Run it in an Administrator terminal with
64-bit Windows PowerShell 5.1.

All four values are collected before setup starts:

| Prompt | Behaviour |
| --- | --- |
| Kiosk User | Suggests an existing SELISE-KIOSK account, otherwise SELISE. Enter confirms the suggestion; another existing, enabled local account can be entered. |
| Restaurant ID | Required; empty or unsafe URL values are requested again. |
| Kiosk ID | Required; empty or unsafe URL values are requested again. |
| Hostname | Suggests the current Windows computer name; Enter confirms it or a valid manual hostname can be entered. |

The setup uses the selected account's existing `C:\Users\<account>` profile and
the original fixed Edge executable path. Both must exist before changes start.
Restaurant/Kiosk IDs accept letters, digits, dots, underscores, dashes and tildes
so the original launcher command and URL remain safe and retain their structure.

`$HostName` replaces `$ZabbixHostName` in the launcher's `host` parameter.
This setup does not install or configure a Zabbix Agent or rename Windows.

The supplied setup actions are retained: auto-login with the original empty
DefaultPassword, original Edge/gesture settings, Explorer restart, launcher and
Startup BAT creation. The handler checks the resulting registry and file values
before reporting success. A failure remains a failed operation. No additional
Thorough Check report is generated by installation.

The setup file can also be run directly from this folder. The Device Management
handler adds context/admin checks, native exit handling and result verification.
Only SaaS/KIOSK/Apply is enabled; other client/device installations stay pending.
